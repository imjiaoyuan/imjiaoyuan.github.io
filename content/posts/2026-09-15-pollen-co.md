title: 用花粉单细胞转录组检测 crossover
date: 2026-09-15

这套流程出自 Castellani 等人在弥散着丝粒植物 *Rhynchospora breviuscula* 上的工作，他们用花粉核的单细胞转录组把 crossover 定位到了全基因组尺度，论文是 [Nature Plants 10, 423–438 (2024)](https://doi.org/10.1038/s41477-024-01625-y)，代码在 [detectCO_by_scRNAseq](https://github.com/Raina-M/detectCO_by_scRNAseq)。我按这条路线整理了一份单花粉的预处理流程，下面按运行顺序走，STAR 加 WASP 加 cellSNP-lite 的变体放在最后单独一节。

花粉粒是减数分裂的产物，一个花粉核就是一次独立的减数分裂结果。RNA reads 落在杂合位点上时，这条 read 属于哪一套同源染色体可以直接读出来，把两套同源染色体分别记作 Hap1 和 Hap2，基因型是 0|1 或 1|0 的杂合位点叫 phased marker，沿染色体走一遍，Hap1 段与 Hap2 段的交界就是一次 crossover（CO）。减数分裂里还有一类不产生互换的重组，DNA 上换了，两侧的标记没有换手，从标记上看不出来，叫 NCO，这套流程检不出它。CO 本身分两条通路，Class I 依赖 ZMM 通路（MSH4、MSH5、MER3、ZIP4、HEI10、MLH1/3 等基因），受干涉，占多数；Class II 依赖 MUS81，不受干涉，数量少。后面看 CO 分布时着丝粒附近偏稀，就和干涉有关。

配子分箱的思路最早来自 Campoy 等人，上面这项工作在 1,641 个花粉核里拿到 4,047 个 CO，断点中位分辨率约 1.5 Mb；同一株的 63 个 F1 后代作为对照，分辨率能到中位 334 bp，但数量只有 378 个 CO。两者互补，F1 定标、单花粉铺开分布。

## 数据与材料

- 一株杂合度较高的个体，以及这个个体的相化单倍型参考（HiFi 加 Hi-C 组装，或用亲本、长 reads 分相）。没有相化的一套单倍型，等位基因就没法归到 Hap1 或 Hap2。
- 花粉核的 10x scRNA-seq 数据。原始 FASTQ 或带 CB/UMI 的 BAM 都要留，表达矩阵丢掉了 read 级的等位基因证据，光有矩阵做不了。
- 用于验证的 F1 分离群体。自交不亲和的物种能拿到的后代有限，R. breviuscula 只收到 63 株，这个数量决定 F1 那条路只能定标，不能铺分布。
- RNA 覆盖的杂合位点密度是全流程的瓶颈。花粉核转录本本来就少，最终分辨率由每个细胞每条染色体上有 reads 的 phased 位点数决定。

只有单倍体的花粉核能用来定位 CO。花粉母细胞和减数分裂 I/II 期的细胞是二倍体，两套等位基因都在，从它推不出这次减数分裂产生了什么 CO，只能做表达层面的分析。

## 单倍型相化

用 HiFi reads 加 Hi-C 数据直接分出两套单倍型，比先做一套参考再用 reads 投影要稳，因为相化发生在组装阶段，

```bash
hifiasm -o asm/Rbrevi.phased.asm.hic --h1 hic.R1.fastq.gz --h2 hic.R2.fastq.gz hifi.reads.fastq.gz
```

- `-o`，输出前缀。加 `--h1` 和 `--h2` 时，输出的两套组装会按 hap1、hap2 分开。
- `--h1` 与 `--h2`，Hi-C 的 R1 和 R2。Hi-C 连接信息用来把杂合位点分到两套同源染色体上，这一步是相化的关键。
- 最后的位置参数是 HiFi reads。该文用了约 35× 每套单倍型的 HiFi 数据，两套组装分别约 419 Mb 和 391 Mb。

组装出来之后用 Salsa2 挂载到染色体水平，再做几轮人工校正和重新挂载。后续所有命令都在 hap1 这套染色体上进行，所以染色体命名要与 GTF、VCF、BAM 完全一致。

两套单倍型之间要比较一遍共线性和结构变异，

```bash
minimap2 -ax asm5 -t 32 ref/hap1.fa ref/hap2.fa > aln/hap1_vs_hap2.sam
```

- `-ax asm5`，组装对组装比对的预设参数，容错率按同物种设定，适合两套单倍型之间约 1% 到 5% 的差异。
- 两个位置参数依次是 hap1 和 hap2 的序列，参考位置放 hap1。
- 比对结果接着交给 SyRi 和 plotsr，得到共线块、倒位和易位的位置。这些区域里的等位基因差异来自结构差异而不是减数分裂交换，做标记集时要把非一对一共线区排除掉。

没有 Hi-C 或者只有一套组装时，改用 dipcall 把两套单倍型投影到统一坐标，或者用 whatshap 按长 reads 分相，命令见文末的补充一节。

## 参考标记位点

需要的是把两套同源染色体区分开的等位 SNP。用整套短 reads 比对到 hap1，先在这个体上做一遍常规重测序变异检测，

```bash
bowtie2 -p 16 -x index/hap1 -1 clean/wgs.R1.fastq.gz -2 clean/wgs.R2.fastq.gz -S aln/wgs.sam
```

- `-x`，bowtie2 的索引前缀，指向 hap1 的染色体序列。
- `-1` 与 `-2`，双端 reads。短 reads 比对到 hap1，落点就是标记的物理位置。
- `-S`，比对结果先落成 SAM，排序失败不用重新比对。该文用的是约 54× 的 150 bp 双端数据。

比对完先按坐标排序，变异检测要求输入有序：

```bash
samtools sort -@ 16 -o bam/wgs.sorted.bam aln/wgs.sam
```

- `-@ 16`，排序线程数。
- `-o`，直接写 BAM。变异检测要求输入按坐标有序。

排好序建索引，后面按染色体取区间要用：

```bash
samtools index -@ 16 bam/wgs.sorted.bam
```

- 建 .bai 索引，mpileup 按染色体并行时要靠它取区间。

逐位点算等位深度，中间结果先落成 BCF：

```bash
bcftools mpileup -f ref/hap1.fa -a AD,DP -Ou -o vcf/wgs.bcf bam/wgs.sorted.bam
```

- `-f`，参考序列。mpileup 用它做碱基质量重校准。
- `-a AD,DP`，输出等位基因深度和总深度。后面筛标记要用 ALT 深度和等位基因频率，现在不加就再也没有这个字段。
- `-Ou`，输出未压缩 BCF，供管道下一段直接读，比中间写一遍 VCF 快。
- `-o`，中间结果写文件，两步分开跑，call 的参数调错了不用重新 mpileup。

参考个体是二倍体，倍性文件先写好：

```bash
echo -e "*\t*\t*\t*\t2" > markers/ploidy.txt
```

- `echo -e "*\t*\t*\t*\t2"`，倍性文件，五列依次是染色体、起始、终止、性别和倍性，第一列用星号表示对全部染色体生效。参考个体是二倍体，这里写 2；逐细胞检测时要把这个 2 改成 1。

按这份倍性文件判基因型，得到参考层面的 SNP：

```bash
bcftools call -m -A -v --ploidy-file markers/ploidy.txt -Oz -o vcf/wgs.snps.vcf.gz vcf/wgs.bcf
```

- `-m`，多等位模型，对应 `--multiallelic-caller`。
- `-A`，保留所有可能的等位基因，对应 `--keep-alts`。两套单倍型之间同一个位点可能出现两个以上的等位基因。
- `-v`，只输出变异位点，对应 `--variants-only`。参考层面不需要未变位点，这一条在逐细胞检测时要拿掉。
- `-Oz`，输出压缩 VCF。

原文这一步用的是 SHOREmap，它把 VCF 转成一张按列读的文本表，之后所有阈值都在这张表上做。

```bash
SHOREmap convert --marker vcf/wgs.snps.vcf.gz --folder markers --runid wgs > markers/convert.log
```

- `--marker`，输入的 VCF，可以用压缩版。
- `--folder` 与 `--runid`，输出目录和这次运行的编号，产出文件名是 `wgs_converted_variant.txt`。
- 输出的文本表里已经把比对质量、ALT 支持数和等位基因频率各算好一列，下一步直接按列号取阈值，不用自己从 INFO 字段里拼。
- 同一个基因家族、同一套单倍型在上下游所有样本上都要用同一份 markers 文件，这份表就是这个流程里所有标记的来源。

按阈值筛出等位标记，

```bash
awk '$6>50 && $7>=5 && $7<=30 && $8>=0.4 && $8<=0.6' markers/wgs_converted_variant.txt > markers/ref_markers.tsv
```

- `$6>50`，比对质量下限 50。低于这个值的位点比对位置不确定，两套单倍型的差别可能只是比对错误。
- `$7>=5 && $7<=30`，ALT 支持数在 5 到 30 之间。下限保证不是随机噪音，上限排除塌缩重复区里深度异常高的位点。
- `$8>=0.4 && $8<=0.6`，等位基因频率接近一半一半。这个个体是杂合体，真正的杂合位点两条同源染色体各贡献一半 reads，偏离说明该位点是重复区、组装错误或者旁系同源。
- 这三个阈值要按自己的数据重估，先把比对质量、等位频率、覆盖度的分布画出来，看这几个分布的尾部在哪里，再决定从哪切。

不用 SHOREmap 时，直接从 VCF 里取同样的三列出来做，效果一样，

```bash
bcftools query -f '%CHROM\t%POS\t%REF\t%ALT\t%INFO/MQ\t%INFO/DP4\n' vcf/wgs.snps.vcf.gz > markers/wgs.snps.dp4.tsv
```

- `%INFO/MQ`，平均比对质量，用来排除落在重复区、多重比对位置上的位点。
- `%INFO/DP4`，四个数字，依次是正链 REF、负链 REF、正链 ALT、负链 ALT 的 reads 数。单看 AD 分不出链偏倚，DP4 可以。

DP4 里的四个数用逗号分隔，先换成制表符才能按列取值：

```bash
tr ',' '\t' < markers/wgs.snps.dp4.tsv > markers/wgs.snps.dp4.tab.tsv
```

- `tr ',' '\t'`，DP4 用逗号分隔四个数字，先换成制表符，后面才能按列取值。

按比对质量、支持读数和链偏倚筛一遍，留下可以做标记的位点：

```bash
awk 'BEGIN{OFS="\t"} {mq=$5; ref=$6+$7; alt=$8+$9; dp=ref+alt; if(dp==0) next; af=alt/dp; if(mq>50 && alt>=5 && alt<=30 && af>=0.4 && af<=0.6) print $1,$2,$3,$4}' markers/wgs.snps.dp4.tab.tsv > markers/ref_markers.tsv
```

- `$6+$7` 与 `$8+$9`，两条链上的 REF 支持数与 ALT 支持数，加起来才是这个位点的等位基因频率分母。
- 输出四列，保留 REF 和 ALT 碱基本身，后面的逐细胞判读要按碱基比对而不是按等位基因编号。

数一下剩下多少标记，太少说明阈值给紧了：

```bash
wc -l markers/ref_markers.tsv
```

- 数一下留下多少位点。该文从 1,404,927 个 SNP 里留下 820,601 个标记，摊到约 370 Mb 的染色体上，大概每 kb 两个。量级对了才继续往下走。
- 参考基因组只保留染色体，叶绿体、线粒体和未定位 contig 都不放进来。CO 只在染色体上定义，把它们留在参考里会让标记数看起来更多，实际全是无效位点。

筛出来之后还要再排掉几类位点，它们都能通过上面的阈值，但会把一个假片段顶成一段单倍型，

- 重复序列和高拷贝区里的位点，以及串联重复基因、相似度很高的旁系同源基因里的位点。这类位点两套单倍型的分差可能本来就不存在，或者三个以上拷贝一起凑出一个假的等位频率。
- 结构变异断点附近。断点两侧的坐标在两套单倍型之间对不上，按 hap1 的位置给 read 定坐标本身就是错的。
- InDel 上下游 5 到 10 bp。这里的比对容易整体错位，reference 位置上看到的“SNP”往往是旁边一个 InDel 的副产物。
- 剪接位点附近比对不稳定的位点。跨剪接的 read 落点会在两个外显子之间摇摆。
- 在大量细胞里都表现出异常参考等位基因偏好的位点。一个位点在一半细胞里只出 Hap1、另一半只出 Hap2 是信号；在九成细胞里都偏向 Hap1 就是参考偏倚。

参考偏倚是这条路线上的一个硬问题，reads 全部比对到 hap1，那么携带 hap1 等位基因的 read 天然比携带 hap2 的更少错配、更容易比上，于是真实数据里本来连续的一小段 Hap2 会被偏倚盖过去，看上去仍是一整段 Hap1。三种处理方式选一种，用 WASP 或 variant-masked reference 从源头压住偏倚；给每个位点单独估计参考偏倚并在 HMM 里扣掉；或者至少把全细胞层面的 Hap1 与 Hap2 UMI 总数画出来，看看是不是系统性偏离 1:1。不做这一步，单倍型区段的边界会系统性偏向参考那一套。

另外不要把 hap1 与 hap2 拼接成一套序列再去比对。两套单倍型高度相似，拼接后每个 read 都有两个几乎等价的落点，多重比对暴增，等位基因判读的地基就没了。要一套坐标就只比对 hap1，要两套坐标就用 dipcall 那种投影方式。

## 坏区域与可转录区

标记的物理位置定了，还要排除两类区域。一类是比对本身不可靠的地方，重复序列、低 mappability 区、组装 gap、塌缩高深度区，reads 容易贴到旁系同源或错误位置，等位基因比例随之失真。另一类是两套单倍型本来就不可比的地方，即 hap1 与 hap2 之间的结构变异和非一对一共线区，那里的等位基因差异来自结构差异，与减数分裂交换无关。结构变异断点上下游再各扩 5 kb。

bedtk 是个单文件工具，直接下载即可，`curl -O https://github.com/lh3/bedtk/raw/master/bedtk`；染色体长度文件从参考的 .fai 取前两列，`cut -f1,2 ref/hap1.fa.fai > ref/genome.sizes`。

```bash
bedtools slop -b 5000 -i ref/sv.bed -g ref/genome.sizes > markers/sv.flank5kb.bed
```

- `-b 5000`，区间两端各扩 5000 bp，把结构变异断点上下游一并排除，而不是只排掉断点本身。
- `-i`，结构变异区间的 BED 文件，来自 SyRi 输出的断点。
- `-g ref/genome.sizes`，染色体长度文件，slop 靠它判断区间是否超出染色体末端。

把各类坏区间拼成一个文件，

```bash
cat ref/repeats.bed ref/low_mappability.bed ref/assembly_gaps.bed ref/non_1to1_synteny.bed ref/collapsed_or_high_depth.bed markers/sv.flank5kb.bed > markers/bad.unsorted.bed
```

- 六个文件依次是重复序列注释、低 mappability 区、组装 gap、非一对一共线区、塌缩或异常高深度区，以及上一步扩过的结构变异区间。
- 某类区域暂时没有 BED 文件就从命令里删掉，不要建空占位文件，空文件会让 bedtools 报错或者返回空结果。
- 拼接顺序无所谓，下一步要统一排序。

各类坏区域拼起来之后先排序，bedtools merge 要求输入有序：

```bash
sort -k1,1 -k2,2n markers/bad.unsorted.bed -o markers/bad.sorted.bed
```

- `-k1,1 -k2,2n`，先按染色体再按起点排序。bedtools merge 要求输入有序，这里先排一次，不要留到下一步再排。

合并重叠区间，得到一张不重叠的坏区域表：

```bash
bedtools merge -i markers/bad.sorted.bed > markers/bad_regions.bed
```

- `merge -i`，把重叠或相邻的区间合并成一段，减少后面 intersect 的次数。
- 输出只有三列，区间属于哪一类来源的信息会丢掉，排查某个位点为什么被排除时要回到 bad.sorted.bed 里查。

从注释里取出基因区间，后面判读 CO 要按基因数算证据强度，

```bash
awk 'BEGIN{OFS="\t"} $3=="gene" { gid="."; if (match($0,/gene_id "[^"]+"/)) {gid=substr($0,RSTART+9,RLENGTH-10)}; print $1,$4-1,$5,gid }' ref/annotation.gtf > markers/genes.unsorted.bed
```

- `$3=="gene"`，只在 gene 行上取区间。用 exon 行会把一个基因拆成许多小段，交集时把一个基因里的多个位点算成多个基因。
- `$4-1`，GTF 是 1 基，BED 是 0 基，起点要减一。
- `match($0,/gene_id "[^"]+"/)`，从属性列里取出基因 ID。属性列的格式在不同来源的 GTF 里差异很大，直接用 `$10` 取会错。
- `substr(...,RSTART+9,RLENGTH-10)`，去掉 `gene_id "` 前缀和结尾的引号，只留 ID 本身。

基因区间同样先排序再往下走：

```bash
sort -k1,1 -k2,2n markers/genes.unsorted.bed -o markers/genes.bed
```

- 同样先排序，bedtools 的区间运算都要求输入有序。

## 标记位点与基因的对应

把筛选后的标记转成 BED，同时带上碱基列，供后面逐细胞取交集用，

```bash
awk 'BEGIN{OFS="\t"}{print $1,$2-1,$2,$3,$4}' markers/ref_markers.tsv > markers/ref_markers.bed
```

- 五列依次是染色体、0 基起点、位置、REF 碱基、ALT 碱基。
- 后两列跟着一起转，是因为逐细胞取交集要同时匹配位置和碱基，只比位置会把同一个位置上的不同等位基因混在一起。

从标记里剔掉落在坏区域内的位点：

```bash
bedtools intersect -v -a markers/ref_markers.bed -b markers/bad_regions.bed > markers/good_markers.bed
```

- `-v`，反向选择，取在 bad_regions.bed 里没有交集的位点。写漏了就会得到完全相反的结果，剩下的全是坏区域里的位点。

再只保留落在基因体内的位点，scRNA 的 reads 只在这里有证据：

```bash
bedtools intersect -u -a markers/good_markers.bed -b markers/genes.bed > markers/good_markers.in_genes.bed
```

- `-u`，只输出 A 中与 B 有交集的记录，同一条记录只输出一次，不做笛卡尔展开。
- 限制到基因区间是因为 scRNA 的 reads 只落在基因体内，基因间的标记拿不到任何证据。

BED 的起点列在这里没用，去掉转成四列：

```bash
awk 'BEGIN{OFS="\t"}{print $1,$3,$4,$5}' markers/good_markers.in_genes.bed > markers/CO_markers.tsv
```

- 丢掉 BED 的起点列，得到四列，染色体、位置、REF 碱基、ALT 碱基。逐细胞检测那一步用它建索引。

按这份位点表从参考层面的 VCF 里取子集，得到 CO 标记：

```bash
bcftools view -R markers/good_markers.in_genes.bed -Oz -o markers/CO_markers.vcf.gz vcf/wgs.snps.vcf.gz
```

- `-R`，按 BED 文件保留指定区间的位点。BED 是 0 基、区间左闭右开，bcftools 会自动转换，不用自己加减一。
- 从原始 VCF 而不是从文本表回写，碱基和质量字段都与检测结果一致。

建索引，下一步定点计数要按区间取：

```bash
tabix -p vcf markers/CO_markers.vcf.gz
```

- 索引必须重建。删过位点的 VCF 用旧索引会取到已经删掉的区间。

再把位点和基因对应起来，取交集时同时输出两侧区间：

```bash
bedtools intersect -wa -wb -a markers/good_markers.in_genes.bed -b markers/genes.bed > markers/snp_gene.raw.tsv
```

- `-wa -wb`，同时输出 A 和 B 两侧的区间，这里要用第 7 列也就是基因 ID。

只留染色体、位置和基因 ID 三列：

```bash
awk 'BEGIN{OFS="\t"}{print $1,$3,$7}' markers/snp_gene.raw.tsv > markers/snp_gene.unsorted.tsv
```

- `print $1,$3,$7`，只留染色体、位点位置、基因 ID 三列，把区间坐标丢掉。

去重后得到位点到基因的对应表：

```bash
sort -u markers/snp_gene.unsorted.tsv -o markers/snp_gene.tsv
```

- `sort -u`，去重，得到位点与基因的对应关系表。判读 CO 时按基因数而不是位点数算证据强度，就靠这张表。

## 单细胞数据预处理

这一步是全流程最容易出错的地方。原始 scRNA reads 里混着 barcode 错误、环境 RNA 和双细胞，如果不先在 barcode 层面处理干净，后面每个细胞拿到的等位基因计数都不可信。该文的做法是先纠正 barcode，再按 barcode 计数、设阈值、拆细胞。

```bash
bcctools correct --alts 16 --spacer 12 ref/whitelist_10Xv3.txt raw/R1.fastq.gz raw/R2.fastq.gz > cells/sc_reads_corrected.tsv
```

- `--alts 16 --spacer 12`，细胞 barcode 长 16 bp、UMI 长 12 bp，这是 10x v3 试剂的结构。换成别的版本必须改这两个数字。
- 三个位置参数依次是 10x 官方 barcode 白名单、R1、R2。R1 带 barcode 和 UMI，R2 是转录本序列。
- 纠正发生在 barcode 序列上，一个碱基错的 barcode 会被拉回白名单里最近的那一条。输出表里保留原始 barcode 和纠正后的 barcode 两列，同时把 CB 和 UMI 从 read 里截掉，后面比对的就是纯转录本序列。
- 该文这一步之后剩下 952,535 个可用 barcode。

统计每个 barcode 拿到多少 reads，

```bash
cut -f2 cells/sc_reads_corrected.tsv | sort | uniq -c | awk -F"," 'NF==1' | grep -v "\*" > cells/viable_BC.stats
```

- `cut -f2`，取出纠正后的 barcode 列。归并要以纠正后的结果为准，用原始 barcode 会把同一个细胞拆成几个。
- `sort | uniq -c`，`uniq -c` 只对相邻的重复行计数，不先排序会把同一个 barcode 数成好几条。`-c` 在每行前面加上 read 数，输出两列，第一列是计数，第二列是 barcode。
- `-F","`，按逗号切分。带逗号说明该 barcode 可以纠正到多个白名单序列，属于模糊匹配，`NF==1` 只保留没有逗号的行。
- `grep -v "\*"`，去掉带星号的 barcode，星号表示这个 barcode 没能纠正到任何白名单序列。这一条不能省，否则没定下来的 barcode 会跟着往下走。

先按 reads 数筛 barcode，太少的多半是背景液滴：

```bash
awk '$1>5000 {print $2}' cells/viable_BC.stats > cells/viable_BC_gt5k_reads.list
```

- `$1>5000`，read 数阈值。单细胞基因分型要点位上的等位基因证据，reads 太少的 barcode 多半是背景液滴或破裂细胞。该文用 5,000，这个数要按文库总 reads 调，不要照抄。
- 输出只有 barcode 一列，下一步用它筛 reads 表。

用这份 barcode 名单筛 reads 表，只留要分析的单细胞：

```bash
awk 'FNR==NR{a[$1]=$1; next}; $2 in a {print $0;}' cells/viable_BC_gt5k_reads.list cells/sc_reads_corrected.tsv > cells/sc_reads.tsv
```

- `FNR==NR`，awk 读第一个文件时建索引，读第二个文件时按索引筛选，这是用 awk 做集合交集的常规写法。
- `$2 in a`，看该行的纠正后 barcode 是否在合格列表里。
- 输出保持原文件顺序，下一步按 barcode 拆成单细胞文件。筛完就可以把 `sc_reads_corrected.tsv` 删掉，后面不再用它。

按 barcode 把 reads 拆成每细胞一份，这一步在原文里叫 demultiplexing。先按 barcode 拆成一个个小表，

```bash
mkdir -p cells/demultiplexed_cells && cd cells/demultiplexed_cells
```

- 建好目录并切进去，下面那条命令里的 `../sc_reads.tsv` 才找得到。

按 barcode 把 reads 拆成每个细胞一个文件：

```bash
awk '{print>$2".tsv"}' ../sc_reads.tsv
```

- `print>$2".tsv"`，第二个字段是纠正后的 barcode，按它的值决定每一行写进哪个文件，一个 barcode 一个文件。
- 这一步之后每个文件就是一个细胞（或一个背景液滴）的全部 read 记录。

再把小表转成 FASTQ，这一步的关键是把 UMI 写进 read 名，

```bash
for file in *.tsv; do
  BC=${file%.tsv*}
  mkdir -p "$BC" && mv "$file" "$BC/"
  awk '{print "@"$1"_"$4"\tR1\n"$5"\n+\n"$9"\n@"$1"_"$4"\tR2\n"$6"\n+\n"$10}' "$BC/$file" > "$BC/$BC.fastq"
  rm "$BC/$file"
done
```

- `@"$1"_"$4"`，read 名取原始 read 名加 UMI，UMI 必须留在 read 名里。后面的 UMIcollapse 就是靠这个名字把同一条原始分子的多个拷贝认成一组，UMI 没了去重就无从谈起。
- `\tR1` 与 `\tR2`，名字后面标出这条来自 read1 还是 read2。两条 read 用同一个名字，只是后缀不同。
- `$5/$9` 与 `$6/$10`，read1 的序列和质量、read2 的序列和质量，两条一起写进同一个 FASTQ。
- 这一步把双端读成了一对「单端」序列，配对的两条 read 各自独立比对，因为 bcftools 不会在有 mate 未比对的 read 上判读 SNP，而 10x 的 read1 基本都是 barcode 和 UMI，本来就比对不上。用别的工具做配子基因分型时，这一点要先确认。
- 该文这一步之后有 8,001 个细胞，覆盖 77.25% 的原始 read 对。

顺手把这份数据交给 cellranger 跑一遍，用于细胞数、基因数和聚类，

```bash
cellranger count --id=pollen_library01 --transcriptome=ref/cellranger_ref --fastqs=raw --sample=library01 --localcores=32 --localmem=120
```

- `--transcriptome`，cellranger 格式的参考，包含序列、GTF 和过滤后的基因列表，不能直接用 fasta 加 gtf。
- `--fastqs` 与 `--sample`，测序输出目录和样本前缀，cellranger 按前缀找 R1、R2。
- `--localcores` 与 `--localmem`，核数和内存上限，大转录组给到 120 G 以上。
- 这一步只用于统计和聚类，花粉核转录本少，细胞数、每细胞基因数的分布要靠它确认。基因分型不走 cellranger，走下面自己的逐细胞流程。

## 细胞阶段筛选

先只保留减数分裂完成后的单倍体细胞，其余细胞不进入基因分型，

```r
library(Seurat)

# obj 已完成质控、聚类、doublet 判定和细胞阶段注释
keep_stage <- c("free_microspore", "uninucleate_microspore", "bicellular_pollen",
                "mature_pollen", "vegetative_cell", "generative_cell", "sperm_cell")

keep <- obj$developmental_stage %in% keep_stage &
        obj$doublet_class == "singlet" &
        obj$transcriptome_qc_pass

post <- subset(obj, cells = colnames(obj)[keep])
writeLines(colnames(post), "postmeiotic_singlet_barcodes.tsv")
```

- `keep` 是一个逻辑向量，三个条件逐细胞相与，发育阶段在白名单里、是 singlet、通过转录组质控。
- `subset(obj, cells = colnames(obj)[keep])`，按 `keep` 取出对应的 barcode 再选细胞。直接写 `subset(obj, subset = ...)` 也行，但逻辑向量能先打印出来数一下有多少个 TRUE，排查时更方便。
- `%in%`，取减数分裂完成之后的细胞阶段。把花粉母细胞、减数分裂 I/II 细胞和花药体细胞写进来是这套流程里最严重的错误，它们没有单倍体基因型可言。
- `doublet_class == "singlet"`，双细胞是两个细胞共用一个液滴，等位基因混在一起，会在染色体上到处切换。这一轮先用表达矩阵去掉明显的双细胞，后面还要用基因型切换率再筛一遍。
- `writeLines(colnames(post), ...)`，输出 barcode 列表。barcode 必须与 BAM 里的 `CB:Z:` 标签逐字符一致，包括 `-1` 后缀，差一个字符就一个细胞都匹配不上。
- 质控阈值按 library × developmental_stage 分别算中位数加减 3 倍 MAD，不要对所有花粉阶段用一套固定的 nFeature/nCount 阈值。成熟花粉的 UMI 数和基因数天然就低，套营养细胞的阈值会把它们全滤掉。

## 逐细胞比对与去重

逐细胞的 reads 先合成单端再比对。配对的两条 read 只要有一条没落到基因组上，这条 read 就不会参与后面的 SNP 判读，双端信息在这个流程里用不上，合成单端反而省事，也少一半比对参数要调。

比对之前先给 hap1 建一次索引，整个项目只建这一次：

```bash
hisat2-build -p 16 ref/hap1.fa index/hap1_hisat2
```

- `-p 16`，建索引线程数，整个项目只建一次。
- 参考用 hap1 的染色体序列，下面所有细胞和 F1 个体都往这同一套坐标上比对。

每个细胞一个循环，比对、排序、去重一起做，

```bash
for BC in */; do BC=${BC%/}
  hisat2 -p 16 -x index/hap1_hisat2 -U "$BC/$BC.fastq" -S "aln/$BC.sam" --summary-file "aln/$BC.aln.txt"
  samtools sort -@ 8 -o "bam/$BC.sorted.bam" "aln/$BC.sam"
  samtools index "bam/$BC.sorted.bam"
  umicollapse bam -i "bam/$BC.sorted.bam" -o "bam/$BC.sorted.dedup.bam" > "aln/$BC.umi_collapse.log"
  rm "aln/$BC.sam"
done
```

- `-U`，单端模式。前面已经把同一个 barcode 的 read1、read2 都写进一个 FASTQ，配对信息在拆分时丢掉了。
- `-x`，hisat2 的索引前缀，指向 hap1 的染色体。
- `--summary-file`，比对率、多重比对比例另存一份。混物种建库时，这一步的比对率就是判断细胞属于哪个物种的依据；比对率低于 25% 的细胞在下一步丢掉。
- `samtools index` 要在 umicollapse 之前建，它按坐标读 BAM，没有索引会退化成从文件头扫。
- `umicollapse bam`，用 read 名里的 UMI 把同一条原始分子的多个 PCR 拷贝压成一条，输出 `.sorted.dedup.bam`。它同时会打印每个细胞保留了多少条 read，这个数写在 `umi_collapse.log` 里，后面算物种归属要用。
- 每个细胞的 SAM 用完即删。几百上千个细胞，中间文件全留着会占掉不少空间。

比对结果先按 UMI 去重，同一分子的 PCR 拷贝压成一条：

```bash
umicollapse bam -i bam/BC01.sorted.bam -o bam/BC01.sorted.dedup.bam > aln/BC01.umi_collapse.log
```

- `bam` 子命令，在 BAM 上按 UMI 去重，不用把 reads 先导出来。
- `-i` 与 `-o`，输入输出文件。不去重的话，PCR 拷贝会直接变成等位基因比例差异，插补出来的基因型跟着错。
- `-i` 这份 BAM 必须先建索引，所以循环里 `samtools index` 排在 umicollapse 前面。
- 统计信息跟标准输出重定向到 `aln/BC01.umi_collapse.log`，每个细胞保留多少条 read 从里面读。

## 细胞身份判定

同一批测序里混了别的物种或者别的基因型时，先按比对率把细胞分开。做法是把同一个细胞的 reads 分别比到两套参考上，比较两边的比对率，

```bash
hisat2 -p 16 -x index/other_ref -U cells/demultiplexed_cells/BC01/BC01.fastq -S aln/BC01.other.sam --summary-file aln/BC01.other.aln.txt
```

- 与前面那次比对只差 `-x`，换成了另一套参考。
- 两次比对用同一份 FASTQ，结果可比。该文把 R. breviuscula 和 R. tenuis 的核混在一个文库里，靠这一步区分。

顺手记一份比对统计，后面判断这个细胞的数据够不够用：

```bash
samtools flagstat bam/BC01.sorted.bam > qc/BC01.flagstat.txt
```

- 输出里 mapped 的百分比就是比对率，用来做两件事，两套参考的比对率都低而且接近的细胞判为双细胞；比对率低于 25% 的细胞直接丢弃。
- 该文 8,001 个细胞里 559 个比对率接近，判为双细胞，4,733 个属于目标物种，其中比对率低于 25% 的再丢掉一批，剩下 4,392 个。

如果没有混样，这一节可以跳过，但比对率仍然值得看一眼，比对率异常的细胞往往是降解的或者双细胞。

## 逐细胞 SNP 检测

逐细胞的变异检测与参考层面用同一套命令，只有一处不同，不加 `--variants-only`，

```bash
bcftools mpileup -f ref/hap1.fa -a AD,DP -Ou -o vcf/BC01.bcf bam/BC01.dedup.bam
```

- 输入是单个细胞的去重 BAM，一个细胞一条命令，比全基因组一起跑省内存得多。
- `-a AD,DP`，单倍体细胞的基因型判定全靠 REF 与 ALT 的读数对比，这两个字段必须输出。

配子是单倍体，倍性文件跟着改：

```bash
echo -e "*\t*\t*\t*\t1" > ploidy.txt
```

- `echo -e "*\t*\t*\t*\t1"`，配子的倍性文件写 1。一个花粉核只有一套染色体，bcftools 按单倍体算基因型似然，顺带在输出里带上准确的 REF/ALT 计数。

按单倍体模型判基因型，同时拿到每个位点的 REF 和 ALT 计数：

```bash
bcftools call -m -A --ploidy-file ploidy.txt -Ov -o vcf/BC01.vcf vcf/BC01.bcf
```

- `-m -A`，多等位模型并保留所有候选等位基因。单细胞 reads 少，同一个位点上偶尔会出现第三种碱基，先都留下，后面按计数判读。
- 不加 `-v`，参考型位点也要输出。某个标记上只有 REF reads 时，这条证据同样说明这个细胞在该位点偏 Hap1，如果只输出变异位点，这类位点会被整段丢掉，块与块之间的空隙会凭空变大。
- 后面判读靠的是计数而不是 bcftools 给的基因型。倍性文件写 1 只是让 call 这一步算得准，不要直接拿它输出的 GT 当最终结果。

把每个细胞的位点读数取出来，并与参考标记取交集，

```bash
bcftools query -f '%CHROM\t%POS\t%REF\t%ALT\t%QUAL\t[%INDEL\t%DP\t%DP4]\n' vcf/BC01.vcf -o cells/BC01.comma.txt
```

- `[ ... ]`，中括号表示逐样本展开，单细胞只有一个样本，加不加结果一样，写成这样是为了跟多样本情形保持一致。
- `%DP4`，四段计数，逗号分隔，正链 REF、负链 REF、正链 ALT、负链 ALT。
- `%INDEL`，这一列在这个流程里没用上，留着是为了让后面的列号固定。

把 DP4 的逗号换成制表符，拆成独立列：

```bash
tr ',' '\t' < cells/BC01.comma.txt > cells/BC01.tabbed.txt
```

- 把 DP4 里的逗号换成制表符，拆完最后一列变成四个独立列。

取两条链上的 REF 与 ALT 计数，写成六列的等位计数表：

```bash
awk '{if ($1 != "ChrC" && $1 != "ChrM") print $1 "\t" $2 "\t" $3 "\t" $8+$9 "\t" $4 "\t" $10+$11}' cells/BC01.tabbed.txt > cells/BC01.input
```

- `$1 != "ChrC" && $1 != "ChrM"`，去掉叶绿体和线粒体。细胞器基因组在花粉里拷贝数高，位点多、看上去证据充足，但它不来自核基因组的两套同源染色体，留在表里会凭空多出一堆“杂合”位点。染色体命名要换成自己参考里的写法。
- `$8+$9` 与 `$10+$11`，DP4 的前两位相加是 REF 支持数，后两位相加是 ALT 支持数。
- `$3` 与 `$4`，REF 和 ALT 碱基。
- 输出 6 列，染色体、位置、REF 碱基、REF 计数、ALT 碱基、ALT 计数。第 4 列和第 6 列是两个等位基因的读数，后面所有判读、切换率统计、CO 调用都按这两列取值，列序不能改。

和参考标记取交集，原文用的是 TIGER 带的脚本，

```bash
perl get_subset.pl cells/BC01.input 1,2 markers/ref_markers.tsv 2,3 0 > cells/BC01.corrected.txt
```

- `1,2` 与 `2,3`，两个文件里分别用于匹配的列号，都是染色体加位置。
- 最后一位 `0`，不做精确匹配，只要求染色体和位置对上。参考标记的碱基写法与逐细胞检测结果允许有差异，写成 1 会丢掉大量位点。
- 这个脚本来自 TIGER，原本就是给 F2 后代做基因分型和 CO 检测用的，同一套表格式在配子这一层直接复用。
- 也可以自己用 awk 做同一件事，原理就是按染色体加位置把两张表对起来，

按参考标记集取子集，只留后面判读要用的位点：

```bash
awk 'BEGIN{OFS="\t"} NR==FNR{m[$1"\t"$2]=1; next} {if(($1"\t"$2) in m && $4+$6>0) print $1,$2,$3,$4,$5,$6}' markers/ref_markers.tsv cells/BC01.input > cells/BC01.corrected.txt
```

- `NR==FNR`，先读参考标记表建索引，再用它筛这个细胞的结果。
- 索引键只用染色体加位置，与 `get_subset.pl` 的 `0` 保持一致。要改成同时比碱基，就把键换成 `$1"\t"$2"\t"$5`，代价是一些测序错误导致的碱基差异会把位点误删。
- `$4+$6>0`，两条等位基因一共没有 read 的位点直接跳过。

数一下这个细胞还剩多少位点：

```bash
wc -l cells/BC01.corrected.txt
```

- 这个数字是细胞在参考标记上拿到的证据量，决定它能不能用来判 CO。该文要求至少 400 个标记，约每 Mb 一个，覆盖全部五条染色体。
- 标记数不足的细胞直接丢弃，不要放宽阈值凑数，标记太少的细胞判出来的块边界是噪音。

估算基因型切换率，

```bash
while read BC
do
  awk '$4!=0 || $6!=0' "cells/${BC}.corrected.txt" > "cells/${BC}.tmp"
  marker_num=`wc -l < "cells/${BC}.tmp"`
  awk '{
      if      ( $4 / ($4+$6) < 0.2) print 0;   # ref genotype
      else if ( $4 / ($4+$6) > 0.8) print 1;   # alt genotype
      else print 0.5;                          # undecided
  }' "cells/${BC}.tmp" > "cells/${BC}_smt_genotypes.txt"
  head -n-1 "cells/${BC}_smt_genotypes.txt" > tmp1
  tail -n+2 "cells/${BC}_smt_genotypes.txt" > tmp2
  switch_num=`paste tmp1 tmp2 | awk '$2-$1!=0' | wc -l`
  echo -e "$BC\t$marker_num\t$switch_num" >> qc/switches.stats
  rm "cells/${BC}.tmp" "cells/${BC}_smt_genotypes.txt" tmp1 tmp2
done < qc/barcode.list
```

- `awk '$4!=0 || $6!=0'`，只拿至少有一条 read 的位点参与统计，全 0 的位点是没测到，不是切换。
- `$4/($4+$6)`，REF 计数占总读数的比例。低于 0.2 定为 REF 基因型（0），高于 0.8 定为 ALT 基因型（1）。
- `else print 0.5`，中间区间标成未定，不归到任何一侧。这一步很重要，单细胞读数少，大量位点落在 0.2 到 0.8 之间，把它们硬判成 0 或 1 会把噪音变成切换。
- `head -n-1` 与 `tail -n+2`，错开一行造出前后两个文件，`paste` 到一起之后每一行就是相邻两个位点的基因型对。注意这里是按文件里的位点顺序比，前一步的 `get_subset.pl` 已经保证位点按坐标排好。
- `$2-$1!=0`，相邻两个基因型不相等就算一次切换，包括 0 到 0.5 这种“一个定下来了、一个还没定”的情况——这是这个统计里偏保守的地方，读到的切换率会比只数 0↔1 高。
- 输出三列，细胞名、标记数、切换次数。

按标记数和切换率筛细胞，双细胞的切换率明显偏高：

```bash
awk '$2>=400' qc/switches.stats | awk '$3/$2<=0.07 {print $1}' > qc/barcode_gt400markers_no_doublets.list
```

- `$2>=400`，先按标记数筛，低于 400 个标记的细胞不进 CO 判读。
- `$3/$2<=0.07`，切换次数除以标记数就是切换率。双细胞里两套单倍型混在一起，沿染色体到处切；单倍体细胞只在真的 CO 处切一下。该文用 0.07 作为界，去掉 402 个细胞。这个值要拿自己的单倍体细胞分布来定，不要照搬。
- 切换次数特别多（例如 ≥100）的 singleton 也建议单独拉出来人工看一眼，脚本里用注释给了这一行。

## CO 判读

读数很脏，插补、环境 RNA 和比对错误都会让单个位点的读数偏离，所以不能逐位点比大小找切换。原文的做法是先平滑再切块，先用相邻标记的等位基因频率平滑，也就是每个标记看它前后各 2 个标记的频率；再用周围标记的基因型做第二轮平滑；然后把基因型相同的连续区段合并成 block；只有长度至少达到 block_size（默认 1 Mb）且包含至少 5 个标记的 block 才给它一个最终基因型；相邻 block 基因型发生转换的位置就是 CO 断点。最后按细胞统计 CO 数，出现两个 CO 的细胞逐个人工复核。

用脚本实现这套逻辑。这个脚本就是该工作当时用的 hapCO_identification.R：

```r
#!/usr/bin/env Rscript
library(optparse)

option_list <- list(
  make_option(c("-i", "--input"), type = "character", help = "单细胞等位计数文件, 6 列: chr pos ref ref_n alt alt_n"),
  make_option(c("-p", "--cell"), type = "character", default = "cell", help = "细胞名 [default %default]"),
  make_option(c("-c", "--min_marker"), type = "integer", default = 500, help = "该细胞的最少标记数 [default %default]"),
  make_option(c("-g", "--genome"), type = "character", help = "染色体长度文件, 两列 chr length"),
  make_option(c("-o", "--outdir"), type = "character", default = "results/hapco", help = "输出目录 [default %default]"),
  make_option(c("-s", "--block_size"), type = "double", default = 1e6, help = "block 最小长度 [default %default]"),
  make_option(c("-n", "--marker_num"), type = "integer", default = 5, help = "block 内最少标记数 [default %default]"),
  make_option("--window", type = "integer", default = 5, help = "平滑窗口, 每个标记连同前后各 2 个 [default %default]"),
  make_option("--baseAF", type = "double", default = 0.3, help = "第一轮按等位频率平滑的阈值 [default %default]"),
  make_option("--windowAF", type = "double", default = 0.4, help = "第二轮按周围标记基因型平滑的阈值 [default %default]"),
  make_option("--genotype", type = "double", default = 0.2, help = "block 最终基因型的判定阈值 [default %default]")
)
opt <- parse_args(OptionParser(option_list = option_list))

d <- read.table(opt$input, header = FALSE, stringsAsFactors = FALSE)
names(d) <- c("chr", "pos", "ref_base", "ref_n", "alt_base", "alt_n")
d$dp <- d$ref_n + d$alt_n
d <- d[d$dp > 0, ]
if (nrow(d) < opt$min_marker) {
  cat(sprintf("%s: 标记数 %d, 少于 %d, 跳过\n", opt$cell, nrow(d), opt$min_marker))
  quit(status = 0)
}

smooth_chr <- function(x) {
  x <- x[order(x$pos), ]
  half <- (opt$window - 1) / 2
  af <- x$alt_n / x$dp
  af_s <- stats::filter(af, rep(1, opt$window) / opt$window, sides = 2)
  af_s[is.na(af_s)] <- af[is.na(af_s)]
  gt <- ifelse(af_s >= 1 - opt$baseAF, 2L, ifelse(af_s <= opt$baseAF, 0L, NA_integer_))
  for (i in which(is.na(gt))) {
    w <- gt[max(1, i - half):min(length(gt), i + half)]
    w <- w[!is.na(w)]
    if (!length(w)) next
    frac_hap2 <- mean(w == 2)
    if (frac_hap2 >= 1 - opt$windowAF) gt[i] <- 2L else if (frac_hap2 <= opt$windowAF) gt[i] <- 0L
  }
  x$gt <- gt
  x$af_s <- as.numeric(af_s)
  x
}

sites <- do.call(rbind, lapply(split(d, d$chr), smooth_chr))
sites <- sites[!is.na(sites$gt), ]

raw_block <- function(x) {
  x <- x[order(x$pos), ]
  r <- rle(x$gt)
  ends <- cumsum(r$lengths)
  starts <- c(1, head(ends, -1) + 1)
  seg <- data.frame(chr = x$chr[1], start = x$pos[starts], end = x$pos[ends],
                    n_marker = as.integer(r$lengths), gt = r$values,
                    af = tapply(x$af_s, rep(seq_along(r$lengths), r$lengths), mean),
                    stringsAsFactors = FALSE)
  seg$len <- seg$end - seg$start + 1
  seg$gt <- ifelse(seg$af >= 1 - opt$genotype, 2L, ifelse(seg$af <= opt$genotype, 0L, NA_integer_))
  seg[!is.na(seg$gt), ]
}

merge_block <- function(x) {
  x <- x[order(x$start), ]
  out <- x[1, , drop = FALSE]
  for (i in seq_len(nrow(x))[-1]) {
    last <- nrow(out)
    if (x$gt[i] == out$gt[last]) {
      out$end[last] <- x$end[i]
      out$n_marker[last] <- out$n_marker[last] + x$n_marker[i]
      out$len[last] <- out$len[last] + x$len[i]
    } else {
      out <- rbind(out, x[i, , drop = FALSE])
    }
  }
  out
}

blocks <- do.call(rbind, lapply(split(sites, sites$chr), raw_block))
blocks <- do.call(rbind, lapply(split(blocks, blocks$chr), merge_block))
blocks <- blocks[blocks$len >= opt$block_size & blocks$n_marker >= opt$marker_num, ]
blocks <- blocks[order(blocks$chr, blocks$start), ]

co <- do.call(rbind, lapply(split(blocks, blocks$chr), function(x) {
  x <- x[order(x$start), ]
  if (nrow(x) < 2) return(NULL)
  idx <- which(diff(x$gt) != 0)
  if (!length(idx)) return(NULL)
  data.frame(chr = x$chr[idx], pos = x$end[idx], left_gt = x$gt[idx], right_gt = x$gt[idx + 1])
}))

dir.create(opt$outdir, showWarnings = FALSE, recursive = TRUE)
write.table(blocks, file.path(opt$outdir, paste0(opt$cell, ".blocks.tsv")),
            sep = "\t", quote = FALSE, row.names = FALSE)
write.table(co, file.path(opt$outdir, paste0(opt$cell, ".co.tsv")),
            sep = "\t", quote = FALSE, row.names = FALSE)
cat(sprintf("%s: %d 个标记, %d 个 block, %d 个 CO\n", opt$cell, nrow(d), nrow(blocks), nrow(co)))

if (!is.null(opt$genome)) {
  chr_len <- read.table(opt$genome, header = FALSE, stringsAsFactors = FALSE)
  names(chr_len) <- c("chr", "len")
  pdf(file.path(opt$outdir, paste0(opt$cell, ".blocks.pdf")), width = 12, height = 2 * nrow(chr_len))
  for (i in seq_len(nrow(chr_len))) {
    ch <- chr_len$chr[i]
    b <- blocks[blocks$chr == ch, ]
    plot(NA, xlim = c(0, chr_len$len[i]), ylim = c(0, 2), yaxt = "n",
         xlab = ch, ylab = "")
    rect(b$start, 0.6, b$end, 1.4, col = ifelse(b$gt == 2, "#D95F02", "#2166AC"), border = NA)
    abline(v = co$pos[co$chr == ch], col = "black", lwd = 2)
  }
  dev.off()
}
```

拿不准参数默认值时先看一眼帮助：

```bash
Rscript hapCO_identification.R --help
```

- 先看一眼参数默认值。脚本的输入只有两个必填项，单细胞等位计数文件和染色体长度文件。

参数定下来就可以逐细胞跑 CO 判读：

```bash
Rscript hapCO_identification.R -i cells/BC01.input -p BC01 -c 400 -g ref/hap1.genome -o results/hapco
```

- `-i`，单个细胞的等位计数文件，就是上面 6 列的格式。
- `-p`，细胞名，写进输出文件名，便于按细胞回溯。
- `-c 400`，该细胞的最少标记数，不足直接跳过。脚本默认 500，这里按原文的 400 放宽，两个值都要在方法里写清楚。
- `-g`，参考基因组的染色体长度文件，用来画 block 图、算物理位置和 block 长度。
- `-o`，输出目录，逐细胞分开写，方便单个细胞重跑。

- `-s --block_size`，block 最小长度，默认 1e6。脚本里的判据是「block 长度 ≥ block_size 且标记数 ≥ marker_num」，两者都满足才给这个 block 定基因型，所以这个值是长度的下限，不是上限。调大可以减少双 CO 假阳性，但会漏掉染色体两端的真实 CO。
- `-n --marker_num`，block 内最少标记数，默认 5，与原文一致。
- `--baseAF`，第一轮按等位频率平滑的阈值，默认 0.3。
- `--windowAF`，第二轮按周围标记基因型平滑的阈值，默认 0.4。
- `--genotype`，block 最终基因型的判定阈值，默认 0.2。
- `--window`，平滑窗口大小，默认 5，即每个标记连同前后各 2 个标记一起平滑，脚本里目前不支持改这个值。

block_size 和 marker_num 是最需要按物种调的两个量。基因组大、转录本稀的物种，单位长度内的可用标记远少于基因组小、表达谱密的物种，同一个 block_size 得到的分辨率完全不同。该文用这套参数在 1,641 个花粉核里拿到 4,047 个 CO，断点中位分辨率约 1.5 Mb，均值约 2.24 Mb，这是花粉核转录本少带来的上限。

自己定判据时，下面这几条是我按单花粉数据的性质加的，原文没有写死，一个候选 CO 两侧各应有至少 3 个 phased 位点、2 个独立基因、2 个连续窗口。一个高表达基因里的 20 个位点只算一份证据，不要用位点数冒充证据强度。

## 断点稳健性

CO 是整段区段支持一个转换点，检验方式也是整段地动它。leave-one-gene-out 依次删掉断点附近任意一个基因的所有标记，CO 仍在才算稳；bootstrap 对支持它的位点和基因做 80% 重抽样，重复 100 到 500 次，要求 80% 以上的重复中能检出且断点区间稳定。高可信的断点区间在 2 Mb 以内，2 到 5 Mb 只能称为宽区间 CO。

下面这些模式优先当作错误或污染处理，一条染色体频繁来回切换；两次转换距离很近而且只由一个基因支持；多个不相关的细胞在完全相同的低 mappability 区或结构变异位点转换；某个细胞同时有高 mixed rate、高 OTH rate 和异常多的转换；CO 恰好落在 phase set 边界上；删掉单个高表达基因后 CO 消失。不要用每条染色体最多两个 CO 这种硬过滤，它同时切掉真实信号和保留假断点。把 CO 总数超过同批细胞中位数加 3 倍 MAD 的细胞标为异常，再联合 mixed rate、OTH rate 和切换模式判断。

## CO 分布与干涉

断点定下来之后才是要回答的生物学问题。原文固定输出这几组统计，便于跨物种比较，

- 每条染色体的 CO 速率，用 1 Mb 滑窗、100 kb 步长算 cM/Mb，再与遗传图谱互相校验。
- 径向分布，把染色体按相对位置分箱统计 CO 密度。R. breviuscula 的结果是明显的远端偏好，着丝粒单元内部完全没有 CO，但着丝粒单元紧邻的区域不受影响，也就是没有经典的着丝粒效应。
- 干涉，用 MADpattern 算重合系数（CoC），chr1 分 18 个区间，chr2 到 chr5 各分 15 个区间，算每一对区间的平均 CoC。Class I 占主导时间距会被推开，CoC 低于 1。
- 与基因组特征的关系，包括 Tyba 重复密度、CENH3 域、基因密度、到端粒的距离、甲基化水平和 GC 含量。该文把这些特征逐层排下来，发现它们只能局部影响 CO 位置，解释不了整体的远端偏好。
- 通路基因表达与 CO 数量的关系，包括 MSH4、MSH5、MER3、ZIP4、HEI10、MLH1/3、MUS81 以及抑制 CO 的 FANCM、RECQ4、FIGL1。

算区间重组频率时，分子是该区间的 CO 数，分母是在这个区间两侧都能定下单倍型的细胞数，不是所有细胞数。直接拿 CO 数除以窗口里的细胞数会系统性低估，一个细胞在 Chr02 上几乎没有表达位点，它没在 Chr02 上检出 CO 只是因为没有覆盖，不是因为没有发生。短区间用 r_i × 100 当近似的 cM，长区间必须套 Haldane 或 Kosambi 的距离函数，因为两端发生双交换的概率随区间变长而不可忽略，直接乘 100 会把长区间的高估。

除了原文那几组统计，这几项也值得一起算，都是同一批断点能直接得到的结果，

- 每个花粉的全基因组 CO 数、每条染色体的平均 CO 数，以及 0、1、2 和多个 CO 的染色体各占多少。CO 数在花粉之间的方差本身就是干涉和热点强度的体现，数字比均值更有信息量。
- 两个 CO 之间距离的分布，也就是干涉。MADpattern 的 CoC 是一张两两区间的矩阵，画成曲线后才能看出多远的距离上干涉开始消失。
- 倒位和大片段插入缺失是否抑制局部 CO。杂合倒位里两套单倍型方向相反，重组产物不成活，表观上就是这段没 CO，做重组景观时要把这些区间标出来而不是当成低重组区。
- 两套单倍型是否 1:1 传递。单花粉水平上全基因组偏离 1:1 通常意味着参考偏倚或参考里某一段压根来自其中一套。
- CO 与基因密度、TE 密度、GC、DNA 甲基化、H3K4me3 和 ATAC 的关系。没有这些数据的先做基因密度和 TE，这两个从注释就能算。
- 性染色体要拆开算。XY 系统里伪常染色体区（PAR）和性别决定区（SDR）的重组机制不同，混在一起算会把 SDR 的抑制信号平掉；SDR 内部的单倍型转换还要优先排查 X/Y 错误比对和组装错误，而不是当成 CO 报出去。

遗传图谱单独做一遍，从参考标记里按 500 kb 窗口、500 kb 步长取每个窗口的中位标记，从第一条到最后一个存在标记的窗口，得到一套稀疏但均匀的标记，再用 LinkageMapView 画图。Marey map 用遗传长度对物理长度做图，遗传长度取标记数超过 2,000 的细胞（该文 81 个）和 F1 群体各算一套。跨物种比较时要提醒自己，CO 分布主要由配对与联会的机制决定，着丝粒结构和表观特征不是唯一的决定因素。换物种时最该重估的是 CO 检出的分辨率，而不是 CO 的数量本身。

## F1 群体验证

同一株的 F1 后代可以独立验证细胞路线判出来的断点，代价是后代数量有限。每株提 DNA 做约 3× 的短 reads 测序，按与参考标记同一套方法检测变异，

```bash
bowtie2 -p 16 -x index/hap1 -1 clean/F1_01.R1.fastq.gz -2 clean/F1_01.R2.fastq.gz -S aln/F1_01.sam
```

- `-1` 与 `-2`，F1 个体的双端 reads，比对到同一套 hap1 参考，与细胞路线的坐标一致。
- `-S`，输出 SAM，接着排序、建索引，命令与前面参考层面完全相同。

F1 这一层从比对结果接着做，先算等位深度：

```bash
bcftools mpileup -f ref/hap1.fa -a AD,DP -Ou -o vcf/F1_01.bcf bam/F1_01.sorted.bam
```

- 与参考层面同一套命令，区别只在输入是单株 F1 的 BAM。

F1 是二倍体，倍性文件与参考层一样写 2：

```bash
echo -e "*\t*\t*\t*\t2" > markers/ploidy.txt
```

- 倍性文件与参考层一样写 2，F1 是二倍体。

同样按二倍体模型判基因型，得到 F1 的 SNP：

```bash
bcftools call -m -A -v --ploidy-file markers/ploidy.txt -Oz -o vcf/F1_01.snps.vcf.gz vcf/F1_01.bcf
```

- `-v`，F1 这一层只要变异位点，参考型位点由遗传图谱的工具自己处理。
- `-A`，保留全部候选等位，F1 在标记位点上是杂合或纯合，两套基因型都要能表示。

把 F1 的 SNP 取成 TIGER 认的表，格式与参考标记那张表一致，

```bash
SHOREmap convert --marker vcf/F1_01.snps.vcf.gz --folder tiger --runid F1_01 > tiger/F1_01.convert.log
```

- `--runid F1_01`，每个 F1 单株一个 runid，输出文件名带上编号，几十株混在一起也不会覆盖。
- 字段顺序要与 `markers/ref_markers.tsv` 完全一致，否则下一步按列号匹配时会错位。

把 F1 的 SNP 取成 TIGER 认的表，

```bash
perl get_subset.pl tiger/F1_01_converted_variant.txt 1,2 markers/ref_markers.tsv 2,3 0 > tiger/F1_01.input.txt
```

- `1,2` 与 `2,3`，两个文件里分别用于匹配的列号，都是染色体加位置。
- 最后一位 `0`，不做精确匹配，只要求染色体和位置对上。参考标记的碱基写法与 F1 检测结果允许有差异，写成 1 会丢掉大量位点。
- 这个脚本来自 TIGER，原本就是给后代群体做基因分型和 CO 检测用的，同一套表格式在配子这一层直接复用。

TIGER 给出潜在的 CO 位置，RTIGER 用 TIGER 校正后的标记给出染色体区段的基因型，两者一致的 CO 才保留。该文 63 株 F1 一共拿到 378 个 CO，断点中位分辨率 334 bp、均值约 2 kb，比细胞路线细一个数量级。两个数据集的分工是 F1 定标、单花粉铺分布，不要混在一起统计。

## 模拟校准

没有召回率和假阳性率，任何 CO 分布规律都站不住。先拿 500 到 1,000 个减数分裂后的细胞做一次摸底，数清四件事，每个细胞检测到多少个杂合位点；这些位点分布在多少条染色体上；相邻有效标记之间隔多远；每条染色体上有多少个能定下单倍型的窗口。这四组数字直接定下这套数据的天花板。

摸底之后按每个细胞每条染色体的真实标记位置和 UMI 深度模拟几种情形，没有 CO，一到三个随机 CO，真实的 missingness，真实的 mixed rate、OTH rate 和错误率，然后跑同一套平滑与过滤流程。判定标准要看三层，单 CO 召回率不低于 80%；无 CO 模拟里的假阳性率不高于 5%；断点中位区间不超过预设分辨率，一般是 2 Mb。三项都过才做全基因组结论。

不过关时的退路是改口径而不是改阈值，如果大部分细胞染色体上的标记间隔超过 5 到 10 Mb，这批数据只适合出候选 CO，需要加单花粉低深度 DNA 测序做正式验证，这是 scRNA-seq 的固有限制，流程上补不回来。

这套流程能得到什么、得不到什么，写结论时要把话说准。10× 3′ 单细胞转录组给出的断点区间通常在 Mb 量级，把它直接叫 CO 精确断点会失真；叫“转录组证据支持的候选 CO 区间”更合适。真要拿这套数据的重组图谱做结论，实验上往往是几件事一起上，花药的 scRNA/snRNA-seq 解析减数分裂各阶段和 CO 调控网络；同一雄株的叶片 WGS 或单倍型解析基因组提供 Hap1/Hap2 标记；FACS 分选成熟花粉核以后做低深度单花粉基因组测序正式定位 CO；对其中一部分 CO 用 KASP、多重 PCR 或靶向测序验证；再用 HEI10 或 MLH1 的免疫荧光焦点数在细胞学层面核对每个减数分裂细胞大概发生了几次 CO。单花粉基因组路线在这类物种上已经被验证可行，它能直接把重组景观恢复出来，而单细胞转录组这条线的价值在于把 CO 的位置与减数分裂过程中的细胞状态、基因表达连起来。

## 补充一：没有相化单倍型时的做法

如果手上只有一套参考组装和长 reads，先用 dipcall 把两套单倍型投影到统一参考坐标，直接得到带相位的杂合位点。分相之后，连续相位的一段标记叫一个 phase set，写在 FORMAT 的 PS 字段里，不同 phase set 之间 0|1 的方向可以任意翻转，这是这条路线上最大的陷阱，

```bash
run-dipcall -t 48 ref/hap1.fa ref/hap1.fa ref/hap2.fa > vars/sample01.dipcall.mak
```

- `-t 48`，比对线程数。
- 三个位置参数依次是参考序列、hap1 序列、hap2 序列。参考取 hap1，后面两个位置就是两套单倍型。
- 输出的是 makefile，不是 VCF。真正的比对在下一步执行，这一步很快。

长读长这一路先用 dipcall 把两套单倍型投到统一坐标：

```bash
make -j 4 -f vars/sample01.dipcall.mak
```

- `-j 4`，同时跑 4 个比对进程。dipcall 把基因组切成很多段，段数远超线程数，先少给几个看内存。
- `-f`，指定上一步生成的 makefile。
- 跑完在 vars/ 下得到 dipcall 的 VCF 和比对结果。

拆多等位位点，

```bash
bcftools norm -f ref/hap1.fa -m -any -Oz -o vars/sample01.dip.norm.vcf.gz vars/sample01.dip.vcf.gz
```

- `-f ref/hap1.fa`，参考序列，norm 用它校验并规范化 REF。
- `-m -any`，把多等位位点拆成多条双等位记录。bcftools 后面的命令和 PLINK 都只认双等位。
- `-Oz`，输出 BGZF 压缩的 VCF。后面还要建索引，不能输出未压缩的 VCF。

筛选双等位 SNP，

```bash
bcftools view -m2 -M2 -v snps -Oz -o vars/sample01.dip.snps.vcf.gz vars/sample01.dip.norm.vcf.gz
```

- `-m2 -M2`，只保留等位基因数为 2 的位点，拆分后剩下的单等位位点在这一步去掉。
- `-v snps`，只看 SNP。CO 判读用的是 SNP，InDel 在这里没有用。

建索引，后面要按区间取位点：

```bash
tabix -p vcf vars/sample01.dip.snps.vcf.gz
```

- `-p vcf`，按 VCF 的坐标规律建 .tbi 索引，后面按区间取子集、isec 都要用它。
- 单条染色体超过 2 Gb 时 .tbi 的 32 位坐标会溢出，要换成 CSI，也就是 `tabix -C -p vcf`。

再用长 reads 独立检测一遍，只保留两套 call 结果一致的位点，相位方向沿用 dipcall 的，

```bash
run_deepvariant --model_type=PACBIO --ref=ref/hap1.fa --reads=aln/sample01.hifi.bam --output_vcf=vars/sample01.deepvariant.vcf.gz --output_gvcf=vars/sample01.deepvariant.g.vcf.gz --num_shards=48
```

- `--model_type=PACBIO`，DeepVariant 的模型必须与测序平台一致。ONT 要用与碱基识别模型匹配的模型，不能用 HiFi 的模型代替。
- `--ref` 与 `--reads`，参考序列和比对好的 BAM，两者必须来自同一套坐标。
- `--output_vcf` 之外还要 `--output_gvcf`，gVCF 留着，后面按区间复查时不用重跑。
- `--num_shards=48`，把基因组切成 48 份并行跑，跑完自动合并成一个 VCF。

DeepVariant 那一路先取双等位杂合 SNP：

```bash
bcftools view -s sample01 -f PASS -m2 -M2 -v snps -g het -Oz -o vars/sample01.deepvariant.het.raw.vcf.gz vars/sample01.deepvariant.vcf.gz
```

- `-s sample01`，只取这一个样本。
- `-f PASS`，只留 PASS 位点。
- `-m2 -M2 -v snps`，双等位 SNP，与 dipcall 那一路保持同一套口径，后面才能取交集。
- `-g het`，只看杂合基因型。纯合位点在两套单倍型之间没有差别，判读不了单倍型。

给每个基因型补上等位基因频率，后面按 VAF 过滤：

```bash
bcftools +fill-tags vars/sample01.deepvariant.het.raw.vcf.gz -Oz -o vars/sample01.deepvariant.het.vaf.vcf.gz -- -t FORMAT/VAF
```

- `+fill-tags`，bcftools 的插件，用来补算注释字段。
- `-t FORMAT/VAF`，给每个基因型加上等位基因频率，后面所有质量过滤都基于 VAF。
- `--` 之后是插件自己的参数，不写 `--` 会被 bcftools 当成主程序的选项。

按基因型质量、深度和等位比例筛一遍，去掉重复区和组装出错的位置：

```bash
bcftools filter -i 'FMT/GQ>=30 && FMT/DP>=10 && FMT/DP<=80 && FMT/VAF>=0.25 && FMT/VAF<=0.75' -Oz -o vars/sample01.deepvariant.het.snps.vcf.gz vars/sample01.deepvariant.het.vaf.vcf.gz
```

- `-i`，保留满足表达式的位点。
- `FMT/GQ>=30`，基因型质量下限，GQ 低说明两种基因型的似然差别不大。
- `FMT/DP>=10 && FMT/DP<=80`，深度下限保证不是随机噪音，上限用于剔除塌缩重复区。上限不要写死，按全基因组深度分布取中位深度的 2 到 2.5 倍。
- `FMT/VAF>=0.25 && FMT/VAF<=0.75`，杂合位点的两种等位基因 reads 应接近一半一半，偏离说明该位点在重复区或组装有错。

两套方法取交集，两边都支持的位置才留下：

```bash
bcftools isec -n=2 -w1 -p isec vars/sample01.dip.snps.vcf.gz vars/sample01.deepvariant.het.snps.vcf.gz
```

- `-n=2`，只取两个文件都有的位点，也就是两套 call 都支持的位点。
- `-w1`，输出写成第一个文件的记录，相位信息也就沿用 dipcall 的。
- `-p isec`，输出目录，文件名固定。

isec 的输出顺序不保证按坐标，先排序再压缩：

```bash
bcftools sort isec/0000.vcf -Oz -o markers/sample01.assembly_read_supported.vcf.gz
```

- `isec/0000.vcf`，isec 的输出编号是固定的，0000 对应第一个输入 VCF 中同时存在于两者交集的部分。
- `bcftools sort`，isec 输出的位点顺序不保证按坐标，要先排序再压缩，否则 tabix 建不了索引。

建好索引，这一步之后才能做分相：

```bash
tabix -p vcf markers/sample01.assembly_read_supported.vcf.gz
```

- 建索引之后才能按区间取标记，后面排除坏区域时要用。

只有一套参考、也没有第二套组装时，用长 reads 按 reads 分相，

```bash
whatshap phase --reference ref/hap1.fa --ignore-read-groups --tag PS -o vars/sample01.whatshap.vcf.gz vars/sample01.deepvariant.het.snps.vcf.gz aln/sample01.hifi.bam
```

- `--reference`，参考序列，必须与 VCF 和 BAM 用的是同一份。
- `--ignore-read-groups`，不按 read group 分开处理，单体样本的所有 reads 一起分相。
- `--tag PS`，在 FORMAT 里写 PS 字段，标记该位点属于哪个 phase set。
- 后面两个位置参数依次是位点 VCF 和长 reads 的 BAM，read 越长相位连得越长。

分相完先看统计，每条 phase set 有多长、分相比例多高：

```bash
whatshap stats --tsv=vars/sample01.whatshap.stats.tsv vars/sample01.whatshap.vcf.gz
```

- `stats`，输出每条 phase set 的长度、位点数和被分相的比例。
- `--tsv`，结果另存成表格，后面要按 phase set 做筛选和统计。

把相位信息导成表，后面按 phase set 筛选：

```bash
bcftools query -f '[%CHROM\t%POS\t%GT\t%PS\n]' vars/sample01.whatshap.vcf.gz > vars/sample01.phase_sets.tsv
```

- `-f`，指定输出列，中括号表示逐样本展开。
- `%PS`，该位点所属的 phase set 编号。同一个染色体上出现多个 PS 编号，说明相位被切成了几段。

一条染色体上有多个互不连接的 phase set 时，不能默认不同 phase set 的第一个 allele 都是 Hap1。此时要么只在单个 phase set 内部检测 CO，结论会被切碎；要么先用亲本数据、Hi-C 或实体 hap1/hap2 把方向统一并连接。没有解决方向之前不要做染色体尺度的 CO 分析，phase set 边界也不是 CO。分相错误最典型的假象是每条染色体都出现一堆 CO，断点全部落在 phase set 交界处。

## 补充二：STAR 加 WASP 加 cellSNP-lite

这条路线不去拆分细胞，直接用 STARsolo 一次跑完 barcode 拆分和比对，再让 cellSNP-lite 在候选位点上按细胞计数。它省掉了逐细胞比对的开销，代价是依赖 STAR 的 barcode 校正和白名单匹配，barcode 结构、试剂版本必须完全对上。

先建 STAR 索引，参考与标记位点都要与前面一致，

```bash
STAR --runMode genomeGenerate --runThreadN 48 --genomeDir star_index --genomeFastaFiles ref/hap1.fa --sjdbGTFfile ref/annotation.gtf --sjdbOverhang 99
```

- `--runMode genomeGenerate`，建索引而不是比对，只跑一次，后面所有文库共用。
- `--runThreadN 48`，建索引的线程数。
- `--genomeFastaFiles` 与 `--sjdbGTFfile`，参考序列和注释，两者必须来自同一套坐标，也要与 `--varVCFfile` 的 VCF 一致。
- `--sjdbOverhang 99`，read 长度减一，双端 150 bp 测序就写 99。写错会让剪接位点比对整体变差。
- `--genomeDir`，索引输出目录，比对时还要用它。

WASP 需要的杂合位点写成未压缩 VCF，

```bash
bcftools view -Ov -o markers/CO_markers.for_STAR.vcf markers/CO_markers.vcf.gz
```

- `-Ov`，输出未压缩 VCF。STAR 的 `--varVCFfile` 认未压缩 VCF，给 .vcf.gz 容易直接报错。
- 只传候选位点，不要传全基因组 VCF。位点越多，WASP 重比对越慢。

比对这一步选项多，一条命令写完，

```bash
STAR --runThreadN 48 --genomeDir star_index --readFilesIn fastq/library01_R2.fastq.gz fastq/library01_R1.fastq.gz --readFilesCommand zcat --soloType CB_UMI_Simple --soloCBstart 1 --soloCBlen 16 --soloUMIstart 17 --soloUMIlen 12 --soloCBwhitelist ref/3M-february-2018.txt --soloFeatures Gene --soloCellFilter EmptyDrops_CR --outFilterMultimapNmax 1 --outSAMtype BAM SortedByCoordinate --outSAMattributes NH HI AS nM NM MD CR CY UR UY CB UB GX GN vA vG vW --varVCFfile markers/CO_markers.for_STAR.vcf --waspOutputMode SAMtag --outFileNamePrefix bam/library01.
```

- `--readFilesIn` 后面先 R2 再 R1，STAR 按这个顺序配对，写反了两端方向错位，等位基因判读全乱。
- `--readFilesCommand zcat`，reads 是 gz 压缩，让 STAR 自己解压，省掉几百 G 的中间 FASTQ。
- `--soloType CB_UMI_Simple`，10x 3' 试剂的 barcode 结构。换成 5' 或其它版本必须改下面的长度。
- `--soloCBstart 1 --soloCBlen 16 --soloUMIstart 17 --soloUMIlen 12`，细胞 barcode 从第 1 位起长 16 bp，UMI 从第 17 位起长 12 bp。这几个数字写错不会报错，只会得到一堆无法匹配白名单的 barcode。
- `--soloCBwhitelist`，细胞 barcode 白名单，必须与试剂版本对应。
- `--soloFeatures Gene`，按基因汇总。后面 cellSNP-lite 只用位点上的 reads，基因层的结果用于细胞筛选。
- `--soloCellFilter EmptyDrops_CR`，用 EmptyDrops 方法区分真实细胞和背景液滴。
- `--outFilterMultimapNmax 1`，只保留唯一比对的 read。多重比对的 read 落在哪里不确定，等位基因判读没有意义。
- `--outSAMtype BAM SortedByCoordinate`，直接输出排好序的 BAM，省掉一次全量排序。
- `--outSAMattributes` 里的 `vA vG vW`，WASP 相关的标签，必须显式加进输出，否则 BAM 里没有 vW 字段，后面的过滤会全部丢 read。`CB UB` 是校正后的 barcode 和 UMI，`CR CY` 是原始值。
- `--varVCFfile`，告诉 STAR 哪些位点是杂合的，它是 WASP 重比对的输入。
- `--waspOutputMode SAMtag`，开启 WASP，把结果写成比对标签。
- `--outFileNamePrefix`，输出前缀，后面所有文件名都由它拼出来。

WASP 这一段从上游的 BAM 开始，先建索引：

```bash
samtools index -@ 16 bam/library01.Aligned.sortedByCoord.out.bam
```

- `-@ 16`，建索引的线程数。索引先建好，后面按区间取子集时不用全文件扫描。

去掉 WASP 没过关的 read，

```bash
samtools view -h -o bam/library01.aligned.sam bam/library01.Aligned.sortedByCoord.out.bam
```

- `-h`，连头部一起输出，下一步 awk 要保留头部。
- `-o`，写到文件而不是标准输出。转成 SAM 是为了能用 awk 直接筛标签。

只留头部和通过 WASP 过滤的 read，其它位置的比对结果这个流程用不上：

```bash
awk 'BEGIN{OFS="\t"} /^@/ || $0 ~ /vW:i:1/' bam/library01.aligned.sam > bam/library01.wasp_pass.sam
```

- `/^@/ || $0 ~ /vW:i:1/`，保留头部和通过 WASP 的 read。cellSNP-lite 只需要候选位点上的 reads，其它位置的比对结果对这个流程没有用。
- 这里的双竖线是 awk 的逻辑或，与 shell 管道无关，两侧的空格要留着。

转回 BAM，从 SAM 转比直接排 SAM 省磁盘：

```bash
samtools view -bh -o bam/library01.wasp_pass.unsorted.bam bam/library01.wasp_pass.sam
```

- `-bh`，输出 BAM 并保留头部。从 SAM 转回 BAM 再排序，比直接排 SAM 省一半磁盘。

按坐标排序，cellSNP-lite 要求输入有序：

```bash
samtools sort -@ 16 -o bam/library01.wasp_pass.bam bam/library01.wasp_pass.unsorted.bam
```

- `-o`，排序结果直接写文件。samtools sort 不接受把 BAM 写到标准输出再重定向。

建索引，后面按位点取 reads 要用：

```bash
samtools index -@ 16 bam/library01.wasp_pass.bam
```

- 排序之后必须建索引。索引缺失时 cellSNP-lite 会退化成全基因组扫描，慢很多。
- 中间 SAM 和 BAM 都很占地方。磁盘紧的话这一整段可以写成一条管道直接出 wasp_pass.bam，代价是出问题时看不到停在哪一步。

用已知的、已分相已过滤的 VCF 定点计数，不要用 mode 2 从 RNA 里重新发现变异，

```bash
cellsnp-lite -s bam/library01.wasp_pass.bam -b results/postmeiotic_singlet_barcodes.tsv -R markers/CO_markers.vcf.gz -O cellsnp/library01 -p 48 --cellTAG CB --UMItag UB --minMAPQ 30 --minLEN 30 --minCOUNT 1 --minMAF 0.0 --exclFLAG UNMAP,SECONDARY,QCFAIL,SUPPLEMENTARY --gzip
```

- `-s -b -R`，输入 BAM、细胞 barcode 列表、位点 VCF。
- `--cellTAG CB --UMItag UB`，用校正后的 barcode 和 UMI，与 STAR 输出的标签一致。
- `--minMAPQ 30`，比对质量下限，低质量比对在重复区很容易落到错误位置。
- `--minLEN 30`，read 长度下限，过滤截短的 read。
- `--minCOUNT 1`，UMI 最少只出现一次的位点也保留，单细胞数据里能用的位点本来就少。
- `--minMAF 0.0`，关闭 MAF 过滤。位点已经在基因组层面确定，聚合 MAF 过滤会删掉真实的低覆盖区。
- `--exclFLAG`，排除未比对、次级、未通过质控和补充比对。
- 不要使用 `--genotype` 参数，那是二倍体模型，配子需要的是 REF 与 ALT 的 UMI 计数加单倍体判读。

输出目录里有 cellSNP.base.vcf.gz 给位点顺序，cellSNP.samples.tsv 给细胞顺序，cellSNP.tag.AD.mtx 是 ALT 计数，cellSNP.tag.DP.mtx 是 REF 加 ALT，cellSNP.tag.OTH.mtx 是其它碱基。

下面这个脚本把这些矩阵转成每个细胞一份的等位计数表，同时算出细胞加染色体层面的筛选指标：

```python
#!/usr/bin/env python3
"""把 cellSNP-lite 的矩阵转成逐细胞等位计数表, 并算细胞 x 染色体的筛选指标"""
import argparse
import gzip
from collections import defaultdict
from pathlib import Path

import numpy as np
from scipy.io import mmread


def read_sites(vcf_gz):
    """读 cellSNP.base.vcf.gz, 返回位点顺序上的染色体、位置、REF、ALT"""
    chrom, pos, ref, alt = [], [], [], []
    with gzip.open(vcf_gz, "rt") as f:
        for line in f:
            if line.startswith("#"):
                continue
            c = line.rstrip("\n").split("\t")
            chrom.append(c[0])
            pos.append(int(c[1]))
            ref.append(c[3])
            alt.append(c[4])
    return chrom, np.array(pos), ref, alt


def read_gene_map(path):
    m = {}
    for line in open(path):
        c, p, g = line.rstrip("\n").split("\t")[:3]
        m[(c, int(p))] = g
    return m


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--cellsnp-dir", required=True, help="cellSNP-lite 的输出目录")
    ap.add_argument("--fai", required=True, help="参考的 .fai")
    ap.add_argument("--gene-map", help="位点与基因的对应表, 三列 chr pos gene")
    ap.add_argument("--out-prefix", required=True)
    ap.add_argument("--min-snps-chr", type=int, default=10)
    ap.add_argument("--min-genes-chr", type=int, default=5)
    ap.add_argument("--min-span", type=float, default=0.50)
    ap.add_argument("--max-gap", type=int, default=5000000)
    ap.add_argument("--max-mixed-local", type=float, default=0.10)
    ap.add_argument("--max-oth-local", type=float, default=0.05)
    ap.add_argument("--min-dp2-for-mixed", type=int, default=10)
    ap.add_argument("--min-eligible-chrom-wg", type=int, default=15)
    ap.add_argument("--min-eligible-bp-frac-wg", type=float, default=0.70)
    args = ap.parse_args()

    d = Path(args.cellsnp_dir)
    chrom, pos, ref, alt = read_sites(d / "cellSNP.base.vcf.gz")
    site_base = {(chrom[i], int(pos[i])): (ref[i], alt[i]) for i in range(len(pos))}
    cells = [l.strip() for l in open(d / "cellSNP.samples.tsv")]
    ad = mmread(d / "cellSNP.tag.AD.mtx").tocsr()    # 位点 x 细胞
    dp = mmread(d / "cellSNP.tag.DP.mtx").tocsr()
    oth = mmread(d / "cellSNP.tag.OTH.mtx").tocsr() if (d / "cellSNP.tag.OTH.mtx").exists() else None
    ad_t, dp_t = ad.transpose().tocsr(), dp.transpose().tocsr()
    oth_t = oth.transpose().tocsr() if oth is not None else None

    lengths = {}
    for line in open(args.fai):
        f = line.split("\t")
        lengths[f[0]] = int(f[1])
    gene_map = read_gene_map(args.gene_map) if args.gene_map else {}

    prefix = Path(args.out_prefix)
    prefix.parent.mkdir(parents=True, exist_ok=True)
    cell_dir = Path("cells")
    cell_dir.mkdir(exist_ok=True)

    f_chrom = open(str(prefix) + ".cell_chrom_qc.tsv", "w")
    f_cell = open(str(prefix) + ".cell_qc.tsv", "w")
    f_elig = open(str(prefix) + ".eligible_cell_chrom.tsv", "w")
    f_chrom.write("cell\tchrom\tn_snp\tn_dp2\tn_gene\tspan_frac\tmax_gap\tmixed_rate\toth_rate\n")
    f_cell.write("cell\tn_snp\tmixed_rate\toth_rate\tn_eligible_chrom\tn_eligible_bp\tn_eligible_bp_frac\n")
    f_elig.write("cell\tchrom\tn_snp\tn_gene\tspan_frac\tmax_gap\n")

    pass_barcodes = []
    for ci, cell in enumerate(cells):
        dp_i, ad_i = dp_t.getrow(ci).tocoo(), ad_t.getrow(ci).tocoo()
        oth_i = oth_t.getrow(ci).tocoo() if oth_t is not None else None
        ad_of = dict(zip(ad_i.col, ad_i.data))
        oth_of = dict(zip(oth_i.col, oth_i.data)) if oth_i is not None else {}
        sites = defaultdict(list)     # 每条染色体: (位置, DP, ALT, OTH)
        for i, v in zip(dp_i.col, dp_i.data):
            sites[chrom[i]].append((int(pos[i]), int(v), int(ad_of.get(i, 0)), int(oth_of.get(i, 0))))

        all_vals = [x for v in sites.values() for x in v]
        n_snp = len(all_vals)
        n_dp2 = sum(1 for x in all_vals if x[1] >= 2)
        n_het = sum(1 for x in all_vals if x[2] > 0 and x[1] - x[2] > 0)
        n_oth = sum(x[3] for x in all_vals)
        mixed_all = n_het / n_snp if n_snp else float("nan")
        oth_all = n_oth / (n_oth + sum(x[1] for x in all_vals)) if n_snp else float("nan")

        n_elig, bp_elig, keep = 0, 0, []
        for ch, vals in sites.items():
            vals.sort()
            n = len(vals)
            n_dp2_ch = sum(1 for x in vals if x[1] >= 2)
            genes = {gene_map.get((ch, x[0])) for x in vals}
            genes.discard(None)
            span = (vals[-1][0] - vals[0][0] + 1) / lengths.get(ch, vals[-1][0])
            gaps = [b[0] - a[0] for a, b in zip(vals, vals[1:])]
            max_gap = max(gaps) if gaps else 0
            n_het_ch = sum(1 for x in vals if x[2] > 0 and x[1] - x[2] > 0)
            n_oth_ch = sum(x[3] for x in vals)
            mixed_ch = n_het_ch / n
            oth_ch = n_oth_ch / (n_oth_ch + sum(x[1] for x in vals))
            f_chrom.write("%s\t%s\t%d\t%d\t%d\t%.3f\t%d\t%.4f\t%.4f\n"
                          % (cell, ch, n, n_dp2_ch, len(genes), span, max_gap, mixed_ch, oth_ch))
            if (n >= args.min_snps_chr and len(genes) >= args.min_genes_chr
                    and span >= args.min_span and max_gap <= args.max_gap
                    and n_dp2_ch >= args.min_dp2_for_mixed
                    and mixed_ch <= args.max_mixed_local and oth_ch <= args.max_oth_local):
                n_elig += 1
                bp_elig += vals[-1][0] - vals[0][0] + 1
                keep.append((ch, vals))
                f_elig.write("%s\t%s\t%d\t%d\t%.3f\t%d\n" % (cell, ch, n, len(genes), span, max_gap))

        frac = bp_elig / sum(lengths.values()) if lengths else 0
        f_cell.write("%s\t%d\t%.4f\t%.4f\t%d\t%d\t%.4f\n"
                     % (cell, n_snp, mixed_all, oth_all, n_elig, bp_elig, frac))
        if n_elig >= args.min_eligible_chrom_wg and frac >= args.min_eligible_bp_frac_wg:
            pass_barcodes.append(cell)
            with open(cell_dir / (cell + ".input"), "w") as out:
                for ch, vals in sorted(keep):
                    for p_, dp_v, ad_v, _ in vals:
                        r_, a_ = site_base[(ch, p_)]
                        out.write("%s\t%d\t%s\t%d\t%s\t%d\n" % (ch, p_, r_, dp_v - ad_v, a_, ad_v))

    with open(str(prefix) + ".whole_genome_high_quality_barcodes.tsv", "w") as out:
        for b in pass_barcodes:
            out.write(b + "\n")
    print("细胞 %d 个, 全基因组档通过 %d 个" % (len(cells), len(pass_barcodes)))


if __name__ == "__main__":
    main()
```

用的时候把 cellSNP-lite 的输出目录和参考的 .fai 交给它：

```bash
python cell_chrom_qc.py --cellsnp-dir cellsnp/library01 --fai ref/hap1.fa.fai --gene-map markers/snp_gene.tsv --out-prefix qc/library01 --min-snps-chr 10 --min-genes-chr 5 --min-span 0.50 --max-gap 5000000 --max-mixed-local 0.10 --max-oth-local 0.05 --min-dp2-for-mixed 10 --min-eligible-chrom-wg 15 --min-eligible-bp-frac-wg 0.70
```

- `--cellsnp-dir`，cellSNP-lite 的输出目录，脚本从里面读位点顺序、细胞顺序和三个矩阵。
- `--fai`，参考的 .fai，用来算染色体长度和跨度。
- `--gene-map`，位点与基因的对应表，用来数独立基因数。不传这一项就只算位点数。
- `--out-prefix`，输出前缀，生成 cell_chrom_qc.tsv、cell_qc.tsv、eligible_cell_chrom.tsv 和 whole_genome_high_quality_barcodes.tsv。
- `--min-snps-chr 10`，细胞加染色体层面进入 CO 判读所需的最少 phased 位点数。
- `--min-genes-chr 5`，有等位基因证据的独立基因数下限。
- `--min-span 0.50`，最左与最右位点之间的距离除以染色体长度，低于一半的染色体不参与统计。
- `--max-gap 5000000`，相邻可见位点的最大间隔，超过 5 Mb 说明中间有一段没有证据。
- `--max-mixed-local` 与 `--max-oth-local`，进入局部分析需要满足的整细胞污染指标。某个细胞在目标区间两侧分型很干净，但整个细胞混得厉害时，这个区间的判读同样可疑，所以两套阈值一起用。
- `--min-dp2-for-mixed 10`，深度不小于 2 的位点少于 10 个时，mixed rate 无法可靠估计。这个标记用来区分「真的干净」和「算不出来」，不能把后者当 0。
- `--min-eligible-chrom-wg 15` 与 `--min-eligible-bp-frac-wg 0.70`，全基因组档的硬条件。前者要求至少 15 条染色体达标，后者要求达标染色体的碱基总数占参考的 70% 以上。前者保证不是只靠两三条染色体，后者保证已判读的区间足够长。少一个条件都会让“每个花粉有多少个 CO”这个数被覆盖不足偷偷压低。
- 脚本把参考里所有序列的长度都计入 eligible_bp_fraction。参考里如果有叶绿体、线粒体、未定位 contig，要单独准备一份只含目标染色体的 .fai，否则这个比例会被稀释。

这里判断的单位是细胞加染色体。一个细胞可能在一条染色体上有足够标记，在另一条上几乎没有表达位点，后者不能被当作这条染色体没有 CO，否则会把缺失当成阴性，直接压低 CO 数。常用指标和起始阈值，

- n_snp，有 reads 覆盖的 phased 位点数，起始阈值 8 到 10。
- n_gene，有等位基因证据的独立基因数，起始阈值 4 到 5。
- span_fraction，最左与最右位点之间的距离除以染色体长度，起始阈值 50% 到 60%。
- max_internal_gap，相邻可见位点的最大间隔，起始阈值 5 Mb，做精细定位时 2 Mb。
- mixed_rate，深度不小于 2 的位点中 REF 与 ALT 同时出现的比例。单倍体细胞里出现双等位，通常来自双细胞、环境 RNA 或比对错误。起始阈值 10%，高可信 5%。
- oth_rate，既不是 REF 也不是 ALT 的 UMI 占比，算法是 OTH 计数除以三种计数之和。起始阈值 5%，高可信 3%。

双等位这个指标要看的是深度不小于 2 的位点，深度为 1 的位点上只能看到一个等位基因，把这些位点一并算进去，分母越大分子不动，mixed rate 会被系统性压低。习惯上把这个比例记作 fmixed，起始档位是 5% 以下算可信的单倍体细胞，5% 到 10% 保留但标为低可信，超过 10% 直接排除。

另一头要防的正好相反，不能拿整个细胞的 Hap1 与 Hap2 UMI 总数去判它是不是单倍体。一个真实发生了 CO 的花粉，染色体上本来就会一段是 Hap1、另一段是 Hap2，全细胞的整体比例接近一半一半是正常的，硬压成 1:1 会把真信号筛掉。该看的是 HMM 定完状态之后，每个窗口里与推断状态不一致的 UMI 占比，也就是支持另一个单倍型的 UMI 数除以所有有单倍型信息的 UMI 数，5% 以内很好，5% 到 10% 可以用，10% 到 15% 低可信，超过 15% 通常就该丢。它衡量的是“位点跟不跟得上它所在区段的状态”，而不是整个细胞的等位平衡。

深度不小于 2 的位点太少时 mixed_rate 估计不准，不能把 0 当成没有污染。这些阈值都是起点，需要按数据重新估。用完之后把结果分成三档，

- 全基因组可用，19 条染色体里至少 15 条达标，达标的区段跨度加起来覆盖常染色体 70% 以上，大部分染色体的标记跨度超过 60%，且没有大段超过 5 Mb 的标记空缺，整细胞 mixed rate 不高于 5%、OTH rate 不高于 3%，并且这些比例是在足够多的深度不小于 2 的位点上算出来的。只有这类细胞能参与「每个花粉多少个 CO」的计数，因为少出来的那部分覆盖会被当成没有 CO。
- 局部可用，这个细胞在某条染色体或某个区间两侧能定单倍型，就纳入这个区间的统计。算区间重组频率时分母要用该区间两侧都能判型的细胞数，不是全部细胞数，也不是全部测序细胞数。
- 不可用，定位区间大于 5 Mb、只有少数基因支持、或者 HMM 结果不稳定的，可以留在候选表里，但不能拿去做 hotspot 和精细重组率。

把结果分成这三档而不是给一份保留、删除名单，是为了尽量把 10× 数据用满，一个细胞在一条染色体上有用，就在这条染色体上用它，而不是因为别的染色体没覆盖就整个丢掉。
