这个博客框架有以下几个我比较喜欢的特性：

**短链**

`_slug_hash` 函数根据每个文章的文件名，使用 CRC24 哈希并通过 base36 输出 5 位全小写短链，直接映射到主域名下面，比如 https://jiaoyuan.org/5xbok/，既干净又便于分享，也不会产生冲突。

```python
BASE36 = "0123456789abcdefghijklmnopqrstuvwxyz"
RESERVED_SLUGS = frozenset({"assets", "index", "page", "atom"})

def _crc24(data: bytes) -> int:
    crc = 0xB704CE
    for b in data:
        crc ^= b << 16
        for _ in range(8):
            crc <<= 1
            if crc & 0x1000000:
                crc ^= 0x1864CFB
    return crc & 0xFFFFFF

def _slug_hash(name: str) -> str:
    val = _crc24(name.encode())
    result = []
    while val > 0:
        result.append(BASE36[val % len(BASE36)])
        val //= len(BASE36)
    return "".join(reversed(result)).rjust(5, "0")
```

`load_posts` 读取文章时自动计算短链，并且通过 `used` 集合做唯一性检查，撞了自动加后缀：

```python
def load_posts(cfg, engine):
    used = set()
    for md in sorted(posts_dir.glob("*.md")):
        slug = _slug_hash(md.stem)
        if slug in used or slug in RESERVED_SLUGS:
            i = 1
            while f"{slug}-{i}" in used:
                i += 1
            slug = f"{slug}-{i}"
        used.add(slug)
```

**渲染优化**

现在很多博客框架我觉得都太复杂，为了适应大多数人的要求，加入了很多冗余的功能，我这里想办法减少了前端渲染和 js 的加载。Markdown 的渲染是自己写的，没有用任何现有的解析器。支持的语法包括标题、段落、列表、引用、表格、代码块、行内样式这些常用功能，日常写文章完全够用。

代码块就是纯的 `<pre><code>`，构建时用 `html.escape` 把内容转义后直接输出，不做语法高亮、不加载任何 JS，足够轻快；暗色和亮色都交给站点的 CSS 变量统一处理。

```python
def _render_code_block(self, lines: list[str]) -> str:
    return f"<pre><code>{html.escape('\n'.join(lines))}</code></pre>"
```

页面生成后直接写静态 HTML 文件，由 GitHub Pages 直出，不需要任何后端处理或数据库查询：

```python
def _write(public_dir: Path, rel_out_dir: str, html_text: str) -> None:
    out = public_dir / rel_out_dir
    out.mkdir(parents=True, exist_ok=True)
    out_path = out / "index.html"
    # 内容没变就跳过，避免不必要地修改文件
    if out_path.read_text(encoding="utf-8") == html_text:
        return
    out_path.write_text(html_text, encoding="utf-8")
```

数学公式渲染用的 KaTeX，通过正则检测正文（先剥掉代码块，避免把脚本里的 `$VAR` 误判成公式）里是否包含 `$...$` 或 `$$...$$`，或者 front matter 是否声明 `math: true`，只有在需要的时候才加载 KaTeX 的 CSS 和 JS：

```python
MATH_RE = re.compile(r"\$\$.*?\$\$|\$[^$\n]+\$", re.DOTALL)
_FENCE_RE = re.compile(r"```.*?```", re.DOTALL)
```

**评论系统**

评论暂时走最简单的邮件：每篇文章底部留一个邮箱（`config.py` 里的 `email`），想讨论直接发邮件回复。零依赖、不挂任何第三方组件，也省得再维护一个评论数据库。

```html
<section class="comments">
<p>Talk about this post via <strong>{{email}}</strong></p>
</section>
```

---

整个博客就一个 GitHub 仓库，内容、源码、生成的静态文件都在里面。提交后 GitHub Actions 会自动执行构建，生成 HTML 然后部署到 Pages。整个过程全自动，不用手动敲命令，也不用登录什么后台。本地构建的时候可以用 Makefile：

```
make serve          # 构建并启动开发服务器（热重载）
make build          # 构建静态站点到 public/
make new NAME=xxx   # 创建新文章
make pangu          # 格式化所有文章（pangu 间距、清理多余空行）
```
