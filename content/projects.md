Some open-source projects I develop and maintain.

- **jsrc**[python]: A Python library for bioinformatics and scientific computing, covering sequence processing, genomic selection, gene regulatory networks, and image analysis with lazy-loaded modular CLI. ［[blog](/4kcd2/), [github](https://github.com/imjiaoyuan/jsrc), [pypi](https://pypi.org/project/jsrc/)］
- **jkey**[python]: A pure-Python password manager and TOTP authenticator with AES-256-CBC encryption and local-only storage, compatible with Google Authenticator. ［[blog](/7re93/), [github](https://github.com/imjiaoyuan/jkey), [pypi](https://pypi.org/project/jkey/)］
- **RSS**[python]: An RSS aggregator page that fetches feeds via GitHub Actions on a schedule, filters to the latest 6 days, and deploys to GitHub Pages. ［[github](https://github.com/imjiaoyuan/RSS), [pages](http://jiaoyuan.org/RSS/)］
- **books**[python]: An EPUB-to-HTML reader deployed to GitHub Pages with reading progress memory and ebook editing tools. ［[github](https://github.com/imjiaoyuan/books), [pages](http://jiaoyuan.org/books/)］
- **blog**[python]: A dependency-free static site generator written in Python (~1.3k lines, stdlib only), featuring short hash URLs, KaTeX math, and no-JS-by-default rendering. ［[blog](/5xbok/), [github](https://github.com/imjiaoyuan/imjiaoyuan.github.io)］
