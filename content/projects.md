## Software

Some open-source software I develop and maintain.

- **yak**[rust]: A terminal coding harness in a single Rust binary — a REPL-style chat session with steering, tools, sub-agents and MCP as extensions, per-tool approval policies, a searchable conversation store, and multimodal in/out. ［[blog](/60kw6/), [github](https://github.com/imjiaoyuan/yak), [pages](https://jiaoyuan.org/yak/), [aur](https://aur.archlinux.org/packages/rust-yak-bin)］
- **jsrc**[python]: A bioinformatics CLI spanning sequence extraction, genome statistics, phylogeny and gene regulatory network analysis, with lazy-loaded modules and a built-in plotting toolkit. ［[blog](/4kcd2/), [github](https://github.com/imjiaoyuan/jsrc), [pypi](https://pypi.org/project/jsrc/), [aur](https://aur.archlinux.org/packages/jsrc)］
- **jkey**[python]: A pure-Python vault that fuses a password manager with a TOTP authenticator: import 2FA straight from QR images, encrypt any file, all under AES-256-CBC + HMAC-SHA256 with a 5-minute session cache. ［[blog](/7re93/), [github](https://github.com/imjiaoyuan/jkey), [pypi](https://pypi.org/project/jkey/), [aur](https://aur.archlinux.org/packages/jkey)］
- **blog**[python]: A zero-dependency static site generator (~1.4k lines, stdlib only) with CRC24 short-hash URLs, KaTeX math, and no-JS-by-default rendering. ［[blog](/5xbok/), [github](https://github.com/imjiaoyuan/imjiaoyuan.github.io)］
